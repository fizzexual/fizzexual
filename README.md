## About me

I'm a forward-deployed engineer at **Catwing AI**, based in Sofia, Bulgaria. I build web apps with TypeScript and
React, backends in Python/Django and Node.js, and local-first desktop apps with Rust and Tauri. I care about shipping
software that holds up in production: tests, security and clear docs.

- **Now:** forward-deployed engineer at Catwing AI - Python/Django services, React + TypeScript frontends, AWS.
- **Studying:** Software and Internet Technologies at the Technical University of Varna (2026 - 2030).
- **Side project:** [Sprout](https://github.com/fizzexual/Sprout), a beginner-friendly programming language written from scratch in C.
- **Open to:** remote part-time work, about 30 hours a week (GMT+3).
